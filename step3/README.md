# پروژه تشخیص و طبقه‌بندی تصاویر میوه با پایتون

## معرفی پروژه

هدف این پروژه طراحی یک سیستم هوشمند برای شناسایی و طبقه‌بندی تصاویر چهار نوع میوه با استفاده از روش‌های یادگیری ماشین و یادگیری عمیق است.

در این پروژه چهار کلاس زیر انتخاب شده‌اند:

1. Apple (سیب)
2. Banana (موز)
3. Pomegranate (انار)
4. Watermelon (هندوانه)

روش یادگیری مورد استفاده در پروژه، یادگیری نظارت‌شده (Supervised Learning) است؛ زیرا تصاویر به همراه برچسب مشخص در اختیار مدل قرار می‌گیرند.

## بخش دوم: بارگذاری داده‌ها

در این بخش، اسکریپت‌های پایتون برای آماده‌سازی و بارگذاری تصاویر دیتاست نوشته شده‌اند.

### اهداف این بخش

- دریافت و آماده‌سازی تصاویر چهار کلاس میوه
- خواندن تصاویر با استفاده از Python و کتابخانه Pillow
- استخراج برچسب تصاویر از نام پوشه‌های مربوط به هر کلاس
- شمارش تعداد تصاویر هر کلاس
- بررسی امکان باز شدن فایل‌های تصویری
- نمایش تصاویر نمونه برای اطمینان از صحت بارگذاری
- ذخیره گزارش تعداد تصاویر در فایل CSV

### فایل‌های اصلی

| فایل | توضیح |
|---|---|
| `prepare_dataset.py` | آماده‌سازی و تقسیم تصاویر |
| `dataset_loader.py` | بارگذاری، بررسی و شمارش تصاویر |
| `requirements.txt` | کتابخانه‌های موردنیاز |
| `DATASET.md` | منبع و مجوز دیتاست |

### ساختار پوشه‌های داده


نام پوشه هر تصویر به‌عنوان برچسب آن در نظر گرفته می‌شود.

### کتابخانه‌های موردنیاز

- Python
- NumPy
- Pillow
- Matplotlib
- Pandas

### نصب کتابخانه‌ها

ابتدا محیط مجازی پایتون را فعال کنید و سپس دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

### نحوه اجرای برنامه

ابتدا تصاویر را آماده و تقسیم کنید:

```bash
python prepare_dataset.py
```

سپس اسکریپت بارگذاری داده‌ها را اجرا کنید:

```bash
python dataset_loader.py
```

برنامه تعداد تصاویر هر کلاس را نمایش می‌دهد و چند تصویر نمونه از مجموعه‌های داده را باز می‌کند.

### خروجی بخش دوم

- تعداد تصاویر هر کلاس
- نمایش تصاویر نمونه
- گزارش تعداد تصاویر در فایل `dataset_info.csv`

## آمار توصیفی و تحلیل مجموعه داده

در این مرحله، برای بررسی بهتر مجموعه داده و شناخت ویژگی‌های آماری تصاویر، از معیارهای میانگین (Mean) و واریانس (Variance) استفاده شده است.

هدف از این بخش، بررسی مقادیر رنگی تصاویر و میزان پراکندگی پیکسل‌ها در چهار کلاس میوه شامل سیب، موز، انار و هندوانه است.

### ۱. روش محاسبه آمار

تصاویر ابتدا با استفاده از کتابخانه Pillow خوانده شده و به فضای رنگی RGB تبدیل شدند.

سپس با استفاده از کتابخانه NumPy، میانگین و واریانس مقادیر پیکسل‌ها در سه کانال رنگی زیر محاسبه شد:

- Red (قرمز)
- Green (سبز)
- Blue (آبی)

این محاسبات برای مجموعه‌های آموزش، اعتبارسنجی و آزمون انجام شدند.

### ۲. تعداد تصاویر مجموعه داده

مجموعه داده پروژه شامل ۳۲۰ تصویر است که به شکل زیر تقسیم شده‌اند:

| مجموعه داده | تعداد تصاویر هر کلاس | تعداد کل |
|---|---:|---:|
| Train | ۵۶ | ۲۲۴ |
| Validation | ۱۲ | ۴۸ |
| Test | ۱۲ | ۴۸ |
| **مجموع** | **۸۰** | **۳۲۰** |

هر یک از چهار کلاس دارای ۸۰ تصویر است؛ بنابراین مجموعه داده از نظر تعداد تصاویر کلاس‌ها متوازن است.

### ۳. نتایج میانگین و واریانس کل دیتاست

نتایج محاسبه‌شده برای کل تصاویر مجموعه داده:

| کانال رنگی | میانگین (Mean) | واریانس (Variance) |
|---|---:|---:|
| Red | 158.920 | 5406.520 |
| Green | 127.820 | 6178.928 |
| Blue | 103.102 | 6716.323 |

بر اساس نتایج، میانگین کانال قرمز بیشتر از دو کانال دیگر است. همچنین واریانس کانال آبی مقدار بیشتری دارد که نشان‌دهنده پراکندگی بیشتر مقادیر پیکسل‌های این کانال است.

### ۴. نمودار میانگین کانال‌های رنگی RGB

این نمودار میانگین مقادیر کانال‌های قرمز، سبز و آبی را برای چهار کلاس میوه در مجموعه آموزش مقایسه می‌کند.

![Mean RGB](results/plots/mean_rgb.png)

### ۵. نمودار واریانس کانال‌های رنگی RGB

در این نمودار میزان پراکندگی مقادیر پیکسل‌ها در سه کانال رنگی برای هر کلاس نمایش داده شده است.

![RGB Variance](results/plots/variance_rgb.png)

### ۶. نمودار توزیع تصاویر

این نمودار تعداد تصاویر هر کلاس را در سه مجموعه آموزش، اعتبارسنجی و آزمون مقایسه می‌کند.

![Image Distribution](results/plots/image_distribution.png)

همان‌طور که مشاهده می‌شود، تعداد تصاویر هر کلاس در هر سه مجموعه برابر است و از نظر تعداد نمونه‌ها، تعادل مناسبی بین کلاس‌ها وجود دارد.

### ۷. فایل‌های خروجی

نتایج این مرحله در فایل‌ها و پوشه‌های زیر ذخیره شده‌اند:

### ۸. جمع‌بندی

در این مرحله، با محاسبه میانگین و واریانس کانال‌های رنگی و رسم نمودارهای مربوطه، اطلاعات آماری مجموعه داده بررسی شد.

این نتایج به شناخت بهتر توزیع رنگی تصاویر، بررسی تعادل تعداد نمونه‌ها و تحلیل اولیه ویژگی‌های مجموعه داده کمک می‌کنند.

لازم به ذکر است که میانگین و واریانس رنگی به‌تنهایی برای تشخیص نوع میوه کافی نیستند و در این پروژه به‌عنوان ابزار تحلیل و بررسی داده‌ها مورد استفاده قرار گرفته‌اند.
